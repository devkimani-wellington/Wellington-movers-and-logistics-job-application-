## 🚀 How It Works
1. Applicant visits site
2. Clicks position card → auto-fills Position field
3. Fills form + uploads CV
4. Clicks **Submit via Email**
5. You receive email at Wellington.ke01@gmail.com

## 📦 Installation

### Quick Deploy (2 mins)
1. Save `logo.png` and `index.html` in same folder
2. Go to https://app.netlify.com/drop
3. Drag both files → Get live link
4. Done!

### Formspree Setup
1. Go to https://formspree.io
2. Sign up with `Wellington.ke01@gmail.com`
3. Create New Form → Email: Wellington.ke01@gmail.com
4. Copy Form ID (e.g., `xknlvgdq`)
5. Replace `YOUR_FORMSPREE_ID` in index.html
6. Redeploy
